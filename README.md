# Fern & Clay

Fern & Clay is a portfolio landing page for a neighbourhood plant shop and working greenhouse in Stoke Newington, London. It is built with Next.js, React, TypeScript and Tailwind CSS, then exported as a static site for Sites hosting.

**Live site:** [fern-and-clay-greenhouse.copperbagel1.chatgpt.site](https://fern-and-clay-greenhouse.copperbagel1.chatgpt.site/)

The project includes responsive desktop and mobile layouts, plant availability, care guidance, workshops, opening hours, local delivery details and visit information. The editorial photography was generated specifically for the site.

## Preview the site locally

Install dependencies and start the Next.js development server from the repository root:

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`. Use `npm run build` to produce the deployable static export in `out`.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Static export hosted with Sites
